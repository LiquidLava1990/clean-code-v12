# Security policy

## Supported versions

Security fixes land on `main` and ship in the next tagged release. Only the
latest release receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Report privately through GitHub:
**Security → Report a vulnerability** on
<https://github.com/LiquidLava1990/clean-code-v12/security/advisories/new>.

Include the `cc --version` output, the command you ran, and a minimal
reproducing input if you can. You should get an acknowledgement within
7 days; fixes for confirmed issues are released as soon as practical, with
credit to the reporter unless you prefer otherwise.
